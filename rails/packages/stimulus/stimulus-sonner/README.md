# stimulus-sonner

> ⚠️ **This package has moved to [sonner-stimulus](https://www.npmjs.com/package/sonner-stimulus)**

Please install `sonner-stimulus` instead:

```bash
npm install sonner-stimulus
```

This package re-exports `sonner-stimulus` for backwards compatibility and will continue to receive updates.

## Why the rename?

The package follows the naming convention of the original [Sonner](https://sonner.emilkowal.ski/) library (e.g., `sonner` → `sonner-stimulus`).
